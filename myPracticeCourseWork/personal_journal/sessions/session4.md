## Personal Notes and research following this session
*Which class sessions and personal research refers to technology in this proposal. Link to examples.*
I learned more about how DHCP and DNS work and why they are important in network administration.
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses and other network settings to devices. This reduces the need to configure each device manually.
DNS (Domain Name System) translates domain names into IP addresses, allowing users to access network resources without remembering numerical addresses.
I also continued learning about Ansible and how it can automate configuration tasks across several Ubuntu machines.
Ansible uses YAML playbooks to describe tasks. This makes it easier to repeat the same configuration on multiple servers and reduces the possibility of human errors.
I researched how network administrators can use automation to maintain consistent configurations and improve the reliability of network services.
